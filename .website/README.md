**It's the game you've seen in all the ads.**

On a flight home to Chicago the internet wasn't working, so I looked for a random game on my phone that came pre-installed as bloatware. There was this bubble moving game that turned out to be a pretty fun way to kill time. Back on the ground, I tried to play a few round and found it to be completely riddled with ads.

Astra had just come out, so I wondered if it could one-shot me a better version.  Turns out it can!  So I also wondered if it could one-shot it into a JS 13k entry.  It can do that too. My improvement over the original is that it tells you if how you solved the puzzle was optimal.  The directors cut will even show you where you strayed from the optimal path, and can try to find harder puzzles.

This game has the distinction I think of being the first game that I've made that I spent more time playing than creating (assuming one counts prompting AI as making).
